# General guidance


- Write code, identifiers, and new comments in English.
- Preserve valid `TODO` comments and link-only comments during refactoring.
- Treat `doc/PRD.md` as the product-requirements source and `doc/RUNBOOK.md` as the operational and architecture source when the task requires them.
- Record a requirement as `REQ` only when the user explicitly requires that traceability in the changed code. Do not add explanatory comments solely to record inferred requirements.
