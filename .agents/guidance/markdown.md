# Markdown guidance


- Use concise sections, short paragraphs, and plain, translatable language.
- Use ordered lists for procedures and bullet lists for unordered information.
- Use inline code for paths, flags, and single commands; use language-tagged fences for multi-line examples.
- Use descriptive link text and alt text for images.
- Keep links and commands accurate after edits.

Documentation scope rules in your global agent configuration (for example Claude `CLAUDE.md`) take precedence; do not duplicate them here.
